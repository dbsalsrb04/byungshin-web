개발

  • 초기 화면

    • 클라이밍 기록 리스트
      • 날짜 | 장소 | 간략한 설명(최고도전/해결 난이도, 완등률...)
      • 오른쪽 화면에 간단하게 통계 표
    • [기록 시작]
      • 날짜 및 장소 선택
      • 볼더링, 리드 등등 종목 선택
      • 기록 시작 시 시간 기록
    • 나중에 몸무게도 웹에 통합시켜버릴까..

  • 클라이밍 기록 중 화면

    • 최상단에 장소, 날짜, 시작 후 흐른 시간
    • 난이도별로 카운터(+,-), 시도문제와 푼 문제
    • 최하단에 운동 종료
    • 이후 결과 화면으로

  • 결과 화면

    • 장소, 날짜, 운동 시간
    • 클리어한 문제들
    • 초기 화면으로

실제 사용

  1. 클라이밍 날짜 선택 후
  2. 볼더링, 리드 등등 선택
  3. 난이도(⬛ ~ ⬜)가 뜨는데, 클리어한 문제마다 버튼 눌러 카운트 증가
  4. 운동 완료 후, 결과 화면
  5. 기록 완료 후, [기록]에서 간략하게, 기록을 누르면 자세히 볼 수 있음.
  6. 여러가지 통계(완등률 추이, 실력은 어느정도인지 등등...)
